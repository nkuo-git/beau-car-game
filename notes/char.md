API = drop-in for b2-contract/charstub.js: buildCharacter(look, opts) → {group, height, radius, look, setLook, update, state, dispose}; feet y 0, faces local +x, heading = rotation.y. States idle, walk, run, sit (butt 0.45), fall, getup (1.2 s), punch (0.45 s), wave (1.5 s, right hand now), talk + NEW aim, shoot (0.25 s recoil → aim; C.recoil() for auto). update opts: speed (must equal real forward movement per s; forward only, else feet slide; heading jumps >1.2 rad reset feet), weapon 'pistol'|'long', aimPitch (−0.6…0.8), support (0.32), dir (fall direction: local angle or world {x,z}), hands for sit 'lap'|'bars'|'wheel'|[x,y,z]. C.hand/C.handL (fist centres: +x fingers/barrel, +y thumb, +z back of hand; gun grip at origin, barrel +x, top +y → C.hand.add(gun)), C.eyes (+x view dir), C.lookAt(x,y,z|V3|null), C.onState(new, old), C.yaw, C.info {tris,verts,draws,buildMs}, C.mesh, C.bones (29), C.skeleton. opts {state} (start without blend, e.g. 'sit'), {shadow:false}, {plant:false}. CHARACTER_OPTIONS (screen order, Taiwan-Chinese labels; type absent=pick one, 'color', 'range' (height min/max/minKid/maxKid/step), 'toggle' (mask); fixedColor e.g. 藍白拖, 斗笠). PLAYER_LOOK default player. Look fields: body, age, height, build, skin, face 0|1, 9 hair, 9 tops, 5 bottoms, 4 shoes, 5 hats, glasses, mask, colours, seed. setLook: colour-only = recolour (no rebuild); clothes/hair/shoes = rebuild parts; body/age/height/build = full rebuild.
