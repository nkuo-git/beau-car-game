# 大便龍的改車遊戲

3D 改車遊戲：在白色大理石車庫改車（車色、輪框、套件、寬體、引擎），下車走路、開車出門逛小村莊，
去改車廠、車店、賽車場、快速道路、越野車場、內湖，還有警察、槍店。

- **在瀏覽器玩**：https://nkuo-git.github.io/beau-car-game/
- **裝在 Android 手機**：
  1. 用手機打開 [Releases](https://github.com/nkuo-git/beau-car-game/releases/latest)。
  2. 點最新那一版下面的 `beau-car-game-N.apk` 下載。
  3. 打開下載的檔案安裝（第一次要允許「安裝不明來源的應用程式」）。
  4. 之後有新版本，遊戲裡會跳「App 有新版本／下載安裝」；網頁內容有新版本會跳「有新版本，要更新嗎」，按了才會更新。

以前在「大便龍的萬能軟體」裡的「改車」，現在自己一個 App。開發的說明在 [CLAUDE.md](CLAUDE.md)。
